rqt_reconfigure
==================================================

## 概要
本パッケージは，ROS2ノードのパラメータを外部から操作するGUIを提供するオリジナルの[rqt_reconfigure](https://github.com/ros-visualization/rqt_reconfigure)を，列挙型のパラメータやパラメータ名の階層化に対応するように修正したものである

## 修正点
本パッケージは，オリジナルの[rqt_reconfigure](https://github.com/ros-visualization/rqt_reconfigure)に対し，以下の3点を修正している．

1. オリジナルでは，数値型のパラメータを操作する際にもテキストボックスから直接値を入力するインタフェースになっていた．これをスライダーから入力するよう修正した．
2. オリジナルでは，複数の候補値からパラメータの値を選ぶ列挙型に対応していなかった．これを列挙型のパラメータの値をプルダウンメニューから選択して入力できるように修正した．
3. オリジナルでは，パラメータ名が`'.'`で区切られて階層化されている場合でも，それが無視されてフラットに表示されていた．これを，階層ごとにタブにまとめて表示することにより，視認性を改善した．

## オリジナルバージョンへの追随
本パッケージは，オリジナルの`rolling`ブランチから派生している．今後オリジナルに修正が生じた場合は，随時マージすることにより，本パッケージも追随していく予定である．
